Every macro you own in one window — and the client's own tools one click away.

MacroVault lists every account-wide and character macro you have in a single searchable window. Pick one, read its whole body, and put it straight onto your action bars without opening the macro window, retyping a command or working out which slot it lives in. The same window carries the slash commands you end up typing by hand — /fstack, /etrace, /api, the /console toggles — and a library of ready-made macros you can create in one click.

Built for World of Warcraft: Forever (interface 16001).

Features

Every macro, one list

Account-wide and character macros share one scroll, each tagged with the scope it actually lives in. Search filters on the name and on the body, so you can find a macro by what it does when you have forgotten what you called it.

The macro you select shows its full body, its icon, its slot and its scope, with four things you can do about it:

  • Inject picks the macro up, so one click on an action button drops it there.
  • Edit opens it in the editor without retyping the body.
  • Duplicate copies it so you can change a copy and keep the original.
  • Macro UI opens the game's own macro window when you would rather drag it.

An editor that respects the client's limits

Macros are edited as plain text with the client's real limits applied: 255 characters in the body, 16 characters in the name. Too long is refused with the actual numbers rather than silently truncated.

Each entry shows its body before you commit. Create makes a real in-game macro; Create & pick up makes it and puts it on your cursor in one step. A toggle chooses whether new macros land in your account-wide or character slots.

Sensible about account and character slots

Clients do not agree on which slot index character macros start at, so MacroVault reads the limit from the client — the MAX_ACCOUNT_MACROS and MAX_CHARACTER_MACROS globals where they exist, then Constants, then built-in defaults of 120 account and 30 character slots. Every macro MacroVault creates also records the exact scope of its own slot, so the tags stay right even when the detected boundary is only an estimate.

Opening the window is read-only. It never creates or deletes anything.

Remembers where you left it

The window position, the last tab and your default scope are saved per account in MacroVaultDB.

How to use it

  1. Type /mvault in chat to open the window.
  2. My macros — search, click a macro, then Inject, Edit, Duplicate or Macro UI.
  3. Tools — click an entry. The tool runs immediately; output appears in chat or in the client's own window.
  4. Library — pick a macro, check its body, then Create or Create & pick up.
  5. Close with Escape, or type /mvault again.

Slash commands

CommandWhat it does
/mvault or /macrovaultOpen or close the window
/mvault macrosOpen the My macros tab
/mvault toolsOpen the Tools tab
/mvault libraryOpen the Library tab
/mvault editorOpen the editor
/mvault selftestPrint client and limit diagnostics, then confirm the account/character boundary
/mvault resetForget the saved window position

/mvault selftest is the only thing in the addon that creates a macro on its own: one temporary macro per scope, deleted straight away, so it can report where character macros really begin. Run it out of combat. It prints the client build, the detected split, how many slots you use, and whether the probes confirmed or corrected the boundary.

Compatibility

  • World of Warcraft: Forever — interface 16001 (supported target).
  • The .toc also declares interface 120105, so a modern retail client will load it; Forever is what it is written and tested against.
  • No dependencies and no external libraries. One SavedVariables file for the window position and preferences.
  • Nothing is created, edited or deleted while you are in combat — the addon refuses with a message in chat and you can try again afterwards.

Good to know

  • Capacity numbers: if a client exposes neither MAX_ACCOUNT_MACROS, MAX_CHARACTER_MACROS nor a usable Constants entry, the window shows the built-in defaults of 120 account and 30 character slots until you run /mvault selftest, which measures the real split.
  • Slash tools are UI tools. They toggle debug frames, print information and change console settings. MacroVault never casts, moves or fights for you.
  • Panels stay put. Window position, tab and default scope are the only things stored.
